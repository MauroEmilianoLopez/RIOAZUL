# Cabañas Río Azul · demo
Sitio estático de muestra para las cabañas de Ruta 173 km 33, Valle Grande, San Rafael.

## Archivos
- index.html: página completa, autocontenida y lista para publicar en Vercel.
- styles.css: estilos editables; el HTML también los incluye para que se pueda abrir solo.
- script.js: menú desplegable y año del pie.

## Abrir
Abrir index.html directamente en Chrome o cualquier navegador.

## Publicar en Vercel
Importar el repositorio de GitHub como proyecto estático, sin comando de build y con la raíz del proyecto como directorio de salida.
